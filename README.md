# Чат для MAX

Текстовые сообщения в MAX через [GREEN-API](https://green-api.com/max).

Отправка идёт методом `sendMessage`. Входящие забираются через `receiveNotification`, после обработки уведомление удаляется методом `deleteNotification`. Пока его не удалить, следующее из очереди не придёт.

Файлы и служебные статусы в чат не выводятся: из очереди они всё равно забираются и удаляются, иначе она встанет.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

1. В личном кабинете GREEN-API инстанс MAX должен быть авторизован: приложение MAX → Устройства → войти по QR.
2. На странице ввести `idInstance` и `apiTokenInstance`. Поле `apiUrl` уже заполнено `https://api.green-api.com` — если в кабинете указан другой хост, вписать его.
3. Указать номер получателя, например `79991234567`, и нажать «Создать». Номер проверяется через `checkAccount`. Если аккаунта MAX нет, чат не создаётся.
4. Написать сообщение и отправить. Ответ из приложения MAX появится в этом чате.

Enter отправляет, Shift+Enter переносит строку.

Если у инстанса был указан webhook, при входе он очищается и включаются входящие уведомления. Иначе `receiveNotification` ничего не отдаёт. Такой вызов перезапускает инстанс, ответы могут пойти через пару минут.

Токен и переписка хранятся в localStorage этого браузера. Кнопка выхода токен стирает, чаты этого инстанса остаются на этом компьютере.
